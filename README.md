# Cofre Pessoal

App de gestão financeira pessoal (site estático + Firebase).

- `index.html`: o app inteiro (HTML, CSS e JS).
- `config.js`: configuração do Firebase e e-mail do desenvolvedor.
- `manifest.json`, `sw.js`, ícones: instalação como aplicativo.
- `firestore.rules`: regras de segurança do banco (colar no Firebase → Firestore → Regras).

Publicação: Render → Static Site → este repositório, Publish directory `.`, sem comando de build.
